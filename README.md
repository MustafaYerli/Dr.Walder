# Dr. Ewald Walder - Website

Professionelle Website für Orthopädie & Unfallchirurgie Praxis in Wien.

## 📂 Projektstruktur

```
/app/
├── static-website/          # Statische Website-Dateien
│   ├── index.html          # Haupt-HTML-Datei
│   ├── styles.css          # CSS Styles
│   ├── script.js           # JavaScript
│   ├── README.md           # Technische Dokumentation
│   └── DEPLOYMENT-ANLEITUNG.md  # Upload-Anleitung
└── dr-walder-website.zip   # ZIP-Download (alle Dateien)
```

## 🚀 Verwendung

### Option 1: Einzelne Dateien
Laden Sie die Dateien aus dem Ordner `static-website/` herunter und auf Ihren Webserver hoch.

### Option 2: ZIP-Datei
Laden Sie `dr-walder-website.zip` herunter, entpacken Sie sie und laden Sie den Inhalt auf Ihren Webserver hoch.

## 📖 Dokumentation

- **README.md** (im static-website Ordner) - Technische Details
- **DEPLOYMENT-ANLEITUNG.md** - Schritt-für-Schritt Upload-Anleitung

## ✨ Features

- ✅ Responsive Design
- ✅ Mobile Sticky Footer (Anrufen & Online-Termin)
- ✅ FAQ Accordion
- ✅ Setmore Online-Terminbuchung
- ✅ Google Fonts & Icons via CDN
- ✅ Keine Dependencies - funktioniert auf jedem Webserver

## 🌐 Kompatibel mit

- Alle Standard-Webserver (Apache, Nginx, etc.)
- Shared Hosting
- FTP/SFTP Upload
- Keine Build-Tools oder Node.js erforderlich
